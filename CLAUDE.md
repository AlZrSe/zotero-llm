# CLAUDE.md - Anthropic AI Usage Policy

## ⛔ PROHIBITED: Anthropic/Claude Usage in Development

**This project STRICTLY PROHIBITS the use of Anthropic's Claude models and related technologies FOR CODE DEVELOPMENT.**

### What is Prohibited (Development)

- ❌ Using Claude Code or similar Anthropic-powered coding assistants
- ❌ Generating project code with Claude AI
- ❌ Using Claude to write, refactor, or debug code for this project
- ❌ Submitting code written primarily by Anthropic models
- ❌ Merge requests containing Anthropic-generated code

### Enforcement

- **All merge requests will be screened** for Anthropic/Claude usage
- **Automatic rejection** of any PR containing Anthropic references
- **Code reviews** include checks for prohibited API keys and model configurations

**By contributing to this project, you acknowledge and agree to comply with this policy.**
